# 4W1F 3.4.0 – Release Checklist

Status: **prepared, not installed**

Target: **3.4.0 / Build 2026-09-25.1**

## Included
- Users can delete their own gallery/profile uploads, profile picture and vehicle picture.
- Admin and Owner can manage every uploaded image, including other members' profile and vehicle pictures.
- Seven-day image trash with restore for gallery, profile and vehicle pictures; Admin/Owner can purge immediately.
- Daily automatic physical cleanup of media trash through a protected Edge Function.
- Clear support-ticket success confirmation with ticket number.
- Automatic support workflow: Open → In progress / Waiting for user → Open; only an explicit close action creates Closed.
- Ticket assignment ("Bearbeitet von …") and private internal staff notes.
- Dedicated in-app support dispatch tone for new tickets.
- Selectable in-app vehicle-style notification sounds plus mute.
- Personal Home greeting and quick status tiles.
- Notification Center categories: Announcements, Support, Events, System + Mark all read.
- Short role-aware "What's new?" explanations.
- Shared Crew Places with exact map pin selection in event/announcement editors.
- Per-profile privacy switches for Instagram, vehicle, power, modifications and profile photos.
- Server-side Admin activity history for image, support, crew-place, role/label, event and announcement actions.
- Own-image manager shows public, profile-only and private uploads.

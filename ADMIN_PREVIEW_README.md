# Admin Preview

1. Repo-Dateien ersetzen und committen.
2. Hauptlink öffnen und App installieren.
3. Im Admin Center > Release & System > App verteilen die individuellen Admin-Preview-Links teilen.
4. Änderungswünsche sammeln.

Wichtig: Diese GitHub-Pages-Version ist eine finale Frontend-/Admin-Preview. Daten liegen pro Gerät im Browser. Vor dem breiten Crew-Start werden echter Login, gemeinsame Datenbank, serverseitige Rollen, Push und Live-Sync als Backend ergänzt.
